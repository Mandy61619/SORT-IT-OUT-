# SORT IT OUT!

SORT IT OUT! is a recycling-themed falling-object game created with Phaser 4.
## PLAY THE GAME
[Click here to play SORT IT OUT!](https://mandy61619.github.io/SORT-IT-OUT-/)

## About the Game

This game was adapted from a supplied Phaser falling-object game.

The original mechanics were kept because they matched the findings from our usability study, while the theme, graphics, feedback and gameplay were redesigned around recycling education.

## How to Play

Waste items fall from the top of the screen.

The player moves the recycling bin to collect recyclable items.

Correct items:
- Water bottle
- Plastic bag
- Aluminium can
- Glass bottle

Incorrect items:
- Cigarette butt
- Disposable diaper
- Broken ceramic mug
- Dirty sponge

Correct items give the player points.

If the player collects an incorrect item, the recycling bin changes to an unhappy expression to provide immediate visual feedback.

## Design Changes

The original game was re-skinned with:
- A beach-themed background
- Recycling and waste objects
- A yellow recycling bin character
- New visual feedback for incorrect choices
- Updated game title and branding

The design choices were informed by our usability study. Participants preferred simple and direct movement controls, so the interaction was kept easy to understand and responsive.
